# Humi Naturals - E-commerce Website

A chemical-free hair and beauty e-commerce site for curls, coils and waves.

## Project Description
Humi Naturals is a student-built e-commerce website showcasing natural hair products. Focus on moisture, clean ingredients, and textured hair care.

## Features
- Responsive homepage with hero and featured products
- Shop page with product grid, prices and Add to Cart UI
- About page - brand story and ingredient promise
- Enquiries page with contact form
- Cart and Checkout page structure (front-end only)

## Tech Stack
- HTML5
- CSS3 (custom style.css)
- Google Fonts: Fraunces + Inter
- VS Code + Live Server

## Pages / Sitemap
- index.html - Home
- products.html - Shop
- about.html - About
- enquiries.html - Contact / Enquiries
- cart.html - Cart
- checkout.html - Checkout

## How to Run
1. Clone the repo
2. Open folder `humi-site` in VS Code
3. Right-click `index.html` > Open with Live Server
4. Visit `http://127.0.0.1:5500/index.html`
